เครื่องมืออัปเดตจำนวนสินค้า vRich จากไฟล์ Excel

ประมวลผลในเบราว์เซอร์ของผู้ใช้เท่านั้น ไม่ส่งไฟล์ขึ้นเซิร์ฟเวอร์

ทำงานในเครื่องผู้ใช้เท่านั้น

เว็บนี้ใช้ทำอะไร

เว็บนี้ใช้สร้างไฟล์ vrich_import_update_qty.xlsx สำหรับอัปเดตจำนวนสินค้าเข้า vRich โดยอ่านข้อมูลจากไฟล์ Excel 4 ไฟล์ที่ผู้ใช้เลือกเอง: vRich, JST Item, JST Combo/Set และไฟล์รหัสที่ต้องการปรับ ระบบจะใช้ จํานวนที่ใช้ได้ จาก JST เป็นสต๊อกพร้อมขาย และเปลี่ยนเฉพาะคอลัมน์ จำนวน ใน vRich เฉพาะรหัสที่อยู่ใน Scope ของผู้ใช้ (รวม Family ที่ระบบขยายอย่างปลอดภัย) เท่านั้น

ระบบไม่แก้ไฟล์ต้นฉบับ ไม่ import เข้า vRich เอง ไม่ใช้ API ไม่ดึงเว็บ และไม่อัปโหลดไฟล์ไปที่ใด หลังประมวลผลแล้วต้องตรวจ summary_report.xlsx และ report อื่นก่อนนำไฟล์ไป import ด้วยตัวเอง

ไฟล์ที่ต้องเตรียม

  • stock_vrich619.xlsx คือไฟล์ master จาก vRich ใช้เป็นฟอร์มหลักและข้อมูลสินค้าทั้งแถว
  • Item jsterp.xlsx คือไฟล์ JST Item ใช้คอลัมน์ จํานวนที่ใช้ได้
  • SkuCombine.xlsx คือสูตรสินค้า Combo/Set และจำนวน Component ที่ใช้ต่อ 1 ชุด
  • sold_today.xlsx คือไฟล์รหัสที่ต้องการอัปเดต และทำหน้าที่เป็น Scope/Whitelist ของรอบนั้น

คำเตือนสำคัญ

  • ห้ามนำไฟล์ Excel จริงของบริษัทขึ้น GitHub
  • ห้าม import ถ้าสถานะเป็น FAIL หรือ FAIL_DUPLICATE
  • ถ้าเป็น PASS_WITH_EXCLUSION ต้องมั่นใจว่ารหัสที่ข้ามถูกต้อง
  • ถ้ารหัสใดไม่มีใน JST จริง สามารถเลือกข้ามรายการได้ แต่ผู้ใช้ต้องตรวจสอบและยืนยันเองก่อน
  • Combo ที่ใช้ Component ซึ่งยังถูกขายเดี่ยวหรือถูกใช้ใน Combo อื่นจะถูกบล็อกเป็นค่าเริ่มต้น เพื่อลดความเสี่ยง double counting
  • Component ของ Combo ใช้เพื่อคำนวณเท่านั้น ระบบจะไม่แก้จำนวน Component ใน vRich เว้นแต่ Component นั้นอยู่ใน Scope เอง

ข้อจำกัดเรื่องไฟล์ใหญ่

  • เว็บนี้อ่านไฟล์ Excel ใน browser ของผู้ใช้ จึงใช้หน่วยความจำของเครื่องผู้ใช้โดยตรง
  • ไฟล์ที่ใหญ่มาก หรือมีรูปภาพ/format จำนวนมาก อาจทำให้ browser อ่านไม่ไหว
  • ถ้าไฟล์ใหญ่กว่า 30 MB ระบบจะแสดงคำเตือนก่อนประมวลผล
  • ถ้าไฟล์ใหญ่กว่า 80 MB ระบบจะ block และแนะนำให้ใช้ไฟล์ export แบบไม่มีรูปภาพ หรือใช้เวอร์ชัน Python
  • อนาคตอาจเพิ่มทางเลือก CSV/TSV สำหรับไฟล์ใหญ่ แต่เวอร์ชันนี้ยังประมวลผล Excel เท่านั้น

ขั้นตอนใช้งานแบบละเอียด

  1. โหลดไฟล์จำนวนสินค้าจาก vRich แล้วเตรียมเป็น stock_vrich619.xlsx
  2. โหลดไฟล์ JST Item แล้วเตรียมเป็น Item jsterp.xlsx
  3. โหลดไฟล์สูตร Combo/Set จาก JST เช่น SkuCombine.xlsx
  4. เตรียม sold_today.xlsx ให้มีคอลัมน์รหัสสินค้า — ไฟล์นี้คือ Scope/Whitelist
  5. อัปโหลดไฟล์ทั้ง 4 ช่องด้านล่าง
  6. กด ตรวจสอบไฟล์ เพื่อดูชื่อไฟล์ ชื่อชีต จำนวนแถว และคอลัมน์ที่พบ
  7. กด ประมวลผล
  8. ตรวจ Scope / Family Expansion ว่าระบบขยายเฉพาะรุ่นที่ต้องการ
  9. ตรวจรายการที่ถูกบล็อก เช่น ไม่พบ, ซ้ำ, Combo แชร์ Component หรือแหล่งสต๊อกกำกวม
  10. ดาวน์โหลดไฟล์ผลลัพธ์และ report ทั้งหมด โดยเฉพาะ stock_audit_report.xlsx
  11. ค่อยนำ vrich_import_update_qty.xlsx ไป import เข้า vRich ด้วยตัวเอง
